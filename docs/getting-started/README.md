# Getting Started

This section helps you install NuMojo and run your first example quickly.

## Quick start (Pixi)

1. Clone the repository.
2. Install dependencies with Pixi:
    `pixi install`
3. Run the quickstart example:
    `pixi run mojo run -I . examples/quickstart.mojo`
